# Cloud Deployment (Terraform)

Deploy Mindbase to AWS with high availability.

## Architecture

```
                    ┌─────────────┐
                    │  Route 53   │
                    └──────┬──────┘
                           │
                    ┌──────▼──────┐
                    │     ALB     │
                    └──────┬──────┘
              ┌────────────┼────────────┐
              │            │            │
        ┌─────▼────┐ ┌─────▼────┐ ┌─────▼────┐
        │ API (ECS)│ │ API (ECS)│ │ MCP (ECS)│
        └─────┬────┘ └─────┬────┘ └─────┬────┘
              │            │            │
        ┌─────▼────────────▼────────────▼─────┐
        │     RDS PostgreSQL (Multi-AZ)       │
        │     ElastiCache Redis               │
        │     S3 (attachments)                │
        └─────────────────────────────────────┘
              │
        ┌─────▼────┐
        │ Worker   │ (ECS Service, auto-scaling)
        └──────────┘
```

## Prerequisites

- AWS CLI configured
- Terraform >= 1.5
- Docker images pushed to ECR

## Quick deploy

```bash
cd infra/terraform
cp terraform.tfvars.example terraform.tfvars
# Edit terraform.tfvars with your values

terraform init
terraform plan
terraform apply
```

## Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `aws_region` | AWS region | `eu-central-1` |
| `environment` | Environment name | `production` |
| `db_instance_class` | RDS instance | `db.t4g.medium` |
| `api_desired_count` | API replicas | `2` |
| `worker_desired_count` | Worker replicas | `1` |

## Fault tolerance features

- **RDS Multi-AZ**: automatic failover
- **ElastiCache Redis**: cluster mode with replicas
- **ECS**: health checks, rolling deploys, auto-restart
- **S3**: versioning + cross-region replication (optional)
- **ALB**: multi-AZ load balancing

## Secrets

Store in AWS Secrets Manager:
- `MINDBASE_API_KEY`
- `EMBEDDING_API_KEY`
- Database credentials (auto-generated by RDS)
