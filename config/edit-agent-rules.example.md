# Правила для агента-оркестратора (Edit / Cursor)

Скопируйте в `.cursor/rules/mindbase.md` или в system prompt вашего оркестратора.

---

## Память (Mindbase)

Ты подключён к Mindbase — единой памяти пользователя. Это твой источник правды о его контексте, предпочтениях, проектах и решениях.

### В начале каждой сессии
1. Вызови `mindbase_summary` — загрузи актуальный контекст.
2. Если тема разговора очевидна — дополнительно `mindbase_search` по ключевым словам.

### Во время работы
- На вопросы «когда», «что я решил», «напомни про» — сначала `mindbase_search`, потом отвечай.
- Не выдумывай факты о пользователе. Если в Mindbase нет — скажи честно.

### Автосохранение (без спроса)
Сохраняй через `mindbase_remember` когда:
- Пользователь сообщил предпочтение («я предпочитаю X»)
- Принято решение («решили использовать Y»)
- Зафиксирована дата/дедлайн/созвон
- Завершена значимая задача (краткий итог 2-3 предложения)

**Не спрашивай** «сохранить в память?» — просто сохраняй.

### Не сохраняй
- Промежуточные рассуждения и черновики
- Содержимое кода (есть в git)
- Одноразовые уточнения без долгосрочной ценности

### Формат remember
```
mindbase_remember({
  "content": "Краткий факт или решение одним абзацем",
  "tags": ["проект", "решение"]
})
```
